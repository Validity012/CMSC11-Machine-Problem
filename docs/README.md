## Conventions

- One file per document, kebab-case, no version numbers in the name. Git history is the version.
- Reports go in `reports/` named `YYYY-MM-DD-status-report.pdf`.
- When a decision changes the plan, update the playbook and the wiki in the same commit.
- The README at the repository root carries the build steps and the project overview.
